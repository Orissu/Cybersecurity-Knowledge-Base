## 🛠️ Core Competencies for Pentesting

| Domain | Why It Matters |
|--------|---------------|
| **Linux** | Most servers run Linux. You need to navigate, escalate, and persist. |
| **Windows** | Enterprise networks are Windows/AD. Understand to exploit. |
| **Networking** | Every attack traverses a network. Know the protocols. |
| **Crypto** | Understand what protects data to know how to break it. |
