## 🏆 Les Certifications qui Comptent

### 🟢 TIER 1 — Commence ici (objectif : 6 mois)

#### eJPT — eLearnSecurity Junior Penetration Tester
- **Prix** : ~200$ (exam) — prep gratuite avec INE Starter Pass
- **Durée de préparation** : 1-2 mois
- **Niveau** : Débutant → Intermédiaire
- **Contenu** : Recon, web basics, network attacks, pivoting, Metasploit
- **Format** : Exam 100% pratique (pas de QCM), 3 jours, 20 questions sur un lab
- **Pourquoi la faire** : Première certif concrète, reconnue par les recruteurs FR
- **Ressources** : INE Starter Pass (gratuit), TryHackMe Jr Penetration Tester path
- **Site** : ine.com/certifications/ejpt

---

#### CompTIA Security+
- **Prix** : ~380€
- **Durée de préparation** : 2-3 mois
- **Niveau** : Généraliste
- **Contenu** : Concepts sécu, réseau, conformité, cryptographie, gestion des risques
- **Format** : QCM + questions pratiques, 90 min, 750/900 pour passer
- **Pourquoi la faire** : Très demandée dans les annonces FR, reconnue par les RH
- **Ressources** : Professor Messer (YouTube + site gratuit), Darril Gibson (livre)
- **Site** : comptia.org/certifications/security

---

### 🟡 TIER 2 — Dans 6-12 mois

#### PNPT — Practical Network Penetration Tester (TCM Security)
- **Prix** : ~400$
- **Durée de préparation** : 2-3 mois
- **Niveau** : Intermédiaire
- **Contenu** : Active Directory, pivoting, reporting professionnel, présentation orale
- **Format** : 5 jours de lab + rapport écrit + présentation de 15 min
- **Pourquoi la faire** : Très pratique et réaliste, rapport pro requis (valeur CV)
- **Ressources** : TCM Security Academy, YouTube TCM Security (cours gratuits)
- **Site** : certifications.tcm-sec.com

---

#### HTB CPTS — Certified Penetration Testing Specialist
- **Prix** : ~490$ (inclus HTB Academy path)
- **Durée de préparation** : 3-6 mois
- **Niveau** : Intermédiaire → Avancé
- **Contenu** : Le plus complet du marché (AD, web, pivoting, evasion, reporting)
- **Format** : Lab de 10 jours + rapport professionnel obligatoire
- **Pourquoi la faire** : Très respectée dans la communauté, niveau réel
- **Ressources** : HTB Academy Penetration Tester path (gratuit en partie)
- **Site** : academy.hackthebox.com/preview/certifications/htb-certified-penetration-testing-specialist

---

#### BTL1 — Blue Team Labs Level 1
- **Prix** : ~500$
- **Durée de préparation** : 2-3 mois
- **Niveau** : Intermédiaire
- **Contenu** : SOC, forensics, threat hunting, SIEM (Splunk), phishing analysis
- **Format** : Exam 24h, lab pratique
- **Pourquoi la faire** : Meilleure certif Blue Team entry-level, très reconnue SOC
- **Site** : securityblue.team/btl1

---

### 🔴 TIER 3 — Objectif long terme (12-24 mois)

#### OSCP — OffSec Certified Professional
- **Prix** : ~1500$ (90 jours de lab inclus)
- **Durée de préparation** : 6-12 mois
- **Niveau** : Avancé
- **Contenu** : Pentest complet, buffer overflow, AD, rapport pro
- **Format** : Exam 24h de lab + rapport 24h
- **Pourquoi la faire** : La référence absolue en pentest, ouvre toutes les portes
- **Site** : offsec.com/courses/pen-200

---

#### CRTP — Certified Red Team Professional
- **Prix** : ~350$
- **Contenu** : Active Directory attaque complète (Kerberoasting, DCSync, trusts)
- **Pourquoi** : Spécialisation AD, très valorisée en Red Team
- **Site** : alteredsecurity.com

## 💼 Ce que les Recruteurs Regardent (par ordre)

1. **Projets concrets** — ta KB, tes scripts, tes writeups
2. **Profil TryHackMe/HTB** — rang, machines résolues, activité
3. **Certifications** — confirment et crédibilisent
4. **Diplôme** — ton BUT/Licence suffit pour l'alternance

> 💡 Deux candidats : l'un a Security+ et quelques rooms THM.
> L'autre a eJPT + Security+, profil HTB actif, KB GitHub, et un script perso.
> Le deuxième décroche l'entretien systématiquement.
